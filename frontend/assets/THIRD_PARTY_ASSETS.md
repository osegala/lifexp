# Third-Party Assets

## KayKit Medieval Builder Pack

- Source: https://opengameart.org/content/kaykit-medieval-builder-pack-10
- Creator: Kay Lousberg / KayKit
- License: CC0 1.0 Universal
- Used for: rendered base building tiers and the kingdom map background under `frontend/assets/base`.

The checked-in PNGs are rendered/adapted from the source OBJ/MTL models so the React Native app can use them as lightweight image assets.
